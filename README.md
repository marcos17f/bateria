 Animação de Bateria com HTML e CSS
Este projeto demonstra uma animação visual de uma bateria sendo carregada, utilizando apenas HTML e CSS.

📋 Funcionalidades
Representação gráfica de uma bateria.

Animação contínua de carregamento com mudança de altura e cor.

Design responsivo e centralizado na tela.

Cores indicam os níveis de carga: vermelho → laranja → amarelo → verde.

🚀 Tecnologias Utilizadas
HTML5

CSS3 (Flexbox, animações com @keyframes)
